## Schema

`CrewResponse` (`credagent/schemas.py`, §ARCH 7.11) is the Composer task's `output_pydantic`. Every model is `extra="forbid"`, frozen, and strips whitespace. Cross-field rules (`model_validator`):

- `refusal_reason` is set exactly when `refused` is true, and `intent == "refused"` exactly then too; a refusal is never `grounded`.
- `intent == "status"` requires `application`; an `escalation` requires `application`.
- `grounded` requires `sources`, unless the intent is `status` or `clarify` (those are grounded in the application record or the request itself).
